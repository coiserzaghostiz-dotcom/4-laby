# Новости колледжа

Лабораторная №3. База состоит из четырёх связанных таблиц. Таблицы и индексы создаются миграциями из `database/migrations`. Связи Eloquent описаны в моделях из `app/Models`.

| Откуда | Внешний ключ | Куда |
| --- | --- | --- |
| `users` | `role_id` | `roles.id` |
| `texts` | `category_id` | `categories.id` |
| `texts` | `user_id` | `users.id` |

Каждый из трёх внешних ключей обязательный и индексируется. Пока на запись ссылается другая таблица, база запрещает её удалить. У логина уникальный индекс. Новым и существующим аккаунтам назначается роль читателя по умолчанию.

## Запуск

Нужны PHP 8.2 или новее с PDO SQLite и Composer. В PowerShell из папки проекта:

```powershell
composer install
Copy-Item .env.example .env
php artisan key:generate
php artisan migrate --seed --force
php artisan serve
```

При первом запуске команда миграции создаст файл базы SQLite. Открой http://127.0.0.1:8000. Для примера можно войти как `reporter` с паролем `reporter123`. При переходе со второй работы достаточно остановить сервер и выполнить `php artisan migrate`.

В меню «Категория» сначала открывается «Учёба». Над лентой можно выбрать «Учёбу» или «Спорт». Список категорий берётся из базы данных.
