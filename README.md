# 4 laby

«Новости колледжа» — один сайт на Laravel 12 для четырёх лабораторных. Страницы сделаны на Blade, оформление лежит в `public/style.css`.

## Как запустить

Нужны PHP 8.2 или новее с PDO SQLite и Composer. Открой PowerShell в папке проекта, где лежит файл `artisan`, и выполни:

```powershell
composer install
Copy-Item .env.example .env
php artisan key:generate
php artisan migrate --seed --force
php artisan serve
```

При первом запуске команда миграции создаст файл базы SQLite. Открой http://127.0.0.1:8000. При следующих запусках достаточно команды `php artisan serve`.

| Роль | Логин | Пароль |
| --- | --- | --- |
| Читатель | `reader` | `reader123` |
| Журналист | `reporter` | `reporter123` |
| Администратор | `admin` | `admin123` |

При переходе с лабораторной №3 выполни `php artisan migrate --seed` и назначь уже существующему аккаунту `reporter` роль журналиста через админку.

Регистрация создаёт читателя. Журналист публикует и редактирует свои статьи. Админ может зайти в раздел журналиста, а в админке редактирует, удаляет и блокирует любые статьи и меняет роли других пользователей. Заблокированные статьи пропадают из обеих лент и закрываются по прямой ссылке. Их можно вернуть кнопкой «Разблокировать».

## Что показывать по каждой работе

| Работа | Что проверить | Где смотреть в коде |
| --- | --- | --- |
| №1 | Главная, категория «Учёба», формы журналиста и админа. У всех страниц общие шапка и подвал. | `resources/views`, `resources/views/components`, `public/style.css` |
| №2 | Регистрация по логину, вход и выход. Создать статью, увидеть её первой в ленте и открыть нужную категорию. В карточке видны заголовок, категория и автор. | `AuthController.php`, `JournalistController.php`, `NewsController.php` в `app/Http/Controllers` |
| №3 | Четыре таблицы и связи между ними. | `database/migrations`, `app/Models` |
| №4 | Попробовать открыть админку под журналистом, а раздел журналиста под читателем. Войти как админ и проверить блокировку, редактирование, удаление и смену роли. | `routes/web.php`, `app/Http/Middleware/CheckRole.php`, `app/Http/Controllers/AdminController.php` |

### Таблицы и связи

| Таблица | Что хранится |
| --- | --- |
| `roles` | `id`, название роли |
| `categories` | `id`, название категории |
| `users` | `id`, уникальный `login`, хеш пароля, `role_id`, даты создания и обновления |
| `texts` | `id`, `heading`, `text`, `category_id`, `user_id`, `blocked`, даты создания и обновления |

`users.role_id` ссылается на `roles.id`. Поля `texts.category_id` и `texts.user_id` ссылаются на `categories.id` и `users.id`. Все три внешних ключа обязательные и индексируются. База запрещает удалить роль, категорию или пользователя, пока на эту запись есть ссылки.

В меню «Категория» сначала открывается «Учёба». Над лентой можно выбрать «Учёбу» или «Спорт». Список категорий берётся из базы данных.

## Как открыть отдельный этап

Метки `lab1`, `lab2`, `lab3` и `lab4` соответствуют номерам лабораторных. Чтобы скачать первую работу в отдельную папку, выполни:

```powershell
git clone --branch lab1 https://github.com/coiserzaghostiz-dotcom/4-laby.git news-lab1
cd news-lab1
```

Дальше используй инструкцию из `README.md` выбранного этапа. Для первого этапа база ещё не нужна. Если у тебя ZIP проекта с файлом `news-labs.bundle`, его можно указать вместо адреса GitHub в команде клонирования.

## MySQL или MariaDB в XAMPP

Для запуска через MySQL или MariaDB включи MySQL в XAMPP, создай в phpMyAdmin пустую базу `college_news` и замени строку `DB_CONNECTION=sqlite` в `.env` на эти настройки:

```dotenv
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=college_news
DB_USERNAME=root
DB_PASSWORD=
```

Если в XAMPP задан пароль или другой порт, укажи свои значения. Выполни `php artisan migrate --seed` и `php artisan serve`.
